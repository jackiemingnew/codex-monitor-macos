# ADR 0018：浅色详情与深色胶囊分离

- 日期：2026-09-13
- 状态：接受；交付验证单独记录

## 背景

多层半透明深灰在不同桌面上产生灰雾，任务行状态背景和密集成本说明争夺注意力。用户已选择浅色、克制蓝色强调方案，要求优化设计稿并实现。

## 决策

展开详情保持 520pt，使用不透明暖白表面、深色文本与单一蓝色交互强调；收起胶囊继续白字深色，设置窗口继续使用系统语义色。共用颜色不得意外降低胶囊对比度。

Codex 详情优先展示周额度与今日 Token，7/30 天从属展示，API 等值费用折叠。任务默认五行，可原位展开当前快照已加载任务；展开只改变呈现，不重扫、不发起网络请求、不改变 Store 排序或查询上限。

保留已发布 Today 台账与本地估计的证据区别。今日含已归因子代理不意味着现有 lifetime 已经是父子合计；累计列仍使用原线程计数并在帮助和无障碍说明中写明。可用快照列表外的台账余量只称“其他本地记录”，不得宣称它们均未归因。

展示专用 Token 格式采用整数安全的一位小数与进位；公共 CLI/JSON 和既有 Formatter 合同不修改。Unknown 与零、配额状态与旁路状态继续分离。

## 后果

- 获得稳定桌面对比度、明确的主次层级和较少的常驻文字。
- 图表、Tooltip 与次级详情页需要同步适配浅色；不能只改主面板。
- 新增状态仅用于折叠展示，不持久化业务数据、不新增定时器、扫描器或模型调用。
- 设计参考取 Linear 的紧凑节奏和稀疏强调，不复制其品牌、网站结构或配色。
- 编译和静态测试不替代签名安装版的 520pt 视觉、键盘和辅助功能验证。
